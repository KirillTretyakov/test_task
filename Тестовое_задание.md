### Тестовое задание: Разработка API-эндпоинта для агрегации региональных данных

**Цель:** Разработать легковесный REST API эндпоинт на Python, который принимает название региона, имитирует запрос к базе данных и возвращает структурированную информацию о потребностях по годам. 

### Технические требования

### 1. Стек технологий

* **Язык:** Python
* **Фреймворк:** FastAPI
* **Валидация:** Pydantic

### 2. Входные параметры

* **Метод:** POST
* **Эндпоинт:** /api/v1/staffing/needs
* **Заголовки (Headers):** Обязательное наличие заголовка x-app-token. Если заголовок отсутствует или содержит неверный токен, API должен возвращать стандартную ошибку авторизации HTTP 401 Unauthorized. Значение валидного токена зашить в .env
* **Тело запроса (JSON Body):**

```json
{
  "region": "Название региона"
}
```

### 3. Формат успешного ответа (HTTP 200)

Если данные по региону найдены, API должен вернуть JSON-объект (не забываем про pydantic-валидацию), где ключами являются годы, а значениями — словари с тремя метриками (total - общая кадровая потребность, replacement- замещающая кадровая потребность, additional - дополнительная кадровая потребность): 

```json

{
  "2025": {
    "total": 1500,
    "replacement": 600,
    "additional": 900
  },
  "2026": {
    "total": 1800,
    "replacement": 700,
    "additional": 1100
  }
}
```

### 4. Обработка ошибок

Если переданный регион не найден в базе данных:
* **HTTP Status Code:** 404 Not Found
* **Тело ответа:**: JSON с понятным описанием проблемы, например:

```json
{
  "detail": "Данные по региону 'Вымышленный регион' не найдены в базе данных."
}
```

Если тело запроса некорректно (например, не передано поле region):
* **HTTP Status Code:** 422 Unprocessable Entity

### 5. Имитация работы с БД

На данном этапе интеграция с реальной СУБД не требуется. Напишите слой-заглушку (mock-репозиторий), который хранит тестовые данные во внутреннем словаре приложения (в памяти) минимум для 2–3 реально существующих регионов.

### 6. Результат

Результатом выполненного тестового задания должна быть ссылка на открытый github репозиторий, который содержит исходный код краткий README.md с инструкцией по запуску и примером curl-запроса, содержащего заголовок и JSON-тело, а также .env.example.
